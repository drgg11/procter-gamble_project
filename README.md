# procter-gamble_project

An internal database management tool built during multiple courses held by Procter&Gamble . It features a desktop GUI (Tkinter) for browsing and editing company data across multiple tables, and a REST API (FastAPI) for programmatic access to the Identifiers table. The database runs on SQL Server via SQLAlchemy. Automated tests run on every push through a GitHub Actions CI pipeline, using SQLite so no local database setup is required.
